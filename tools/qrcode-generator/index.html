Error correction level: info
The error correction level (L, M, Q H) is an algorithm that adds redundant backup data to the QR Code pattern, It essentially creates duplicates parts of data and spreads them throughout the code and use the backup data to reconstruct missing pieces and recover the original complete message.

Error correction capability for each level
L (Low): ~7%
M (Medium): ~15%
Q (Quartile): ~25%
H (High): ~30%
